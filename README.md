## Common components libraries  📁
All designs share a common, unified library of symbols and footprints, you can find it here:

| Type | Description |
| ---- | ----------- |
| [**Integrated library**](./Libraries/) | A single file containing the compiled library. Better for portability. |
| [**Independent libraries**](./Libraries/Source/) | Schematic and PCB libraries as independent files. Better for modification of symbols and footprints. |


## Tools 🛠️

These projects would not be possible without the help of

* Altium Designer (v24 or higher) as the **design software**
* JLCPCB for the **design rules** and **manufacturing process**
* **Git** for the merging conflicts and  **GitHub** for sharing those with you
