## Common components libraries  📁
All the designs share a common unified symbol and footprint library, you can find it here:

| Type | Description |
| ---- | ----------- |
| [**Integrated library**](./Libraries/) | A single file with the compiled library, better for portability. |
| [**Independent libraries**](./Libraries/Source/) | The schematic and pcb libraries as independent files, better for changing symbols or footprints. |


## Tools 🛠️

These projects wouldn't be possible without the help of

* Altium Designer (v24 or higher) as the **design software**
* JLCPCB for the **design rules** and **manufacturing process**
* **Git** for the merging conflicts and  **GitHub** for sharing those with you
